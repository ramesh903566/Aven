# Aven

Welcome to **Aven** – a minimalist, high-performance, and intentionally designed personal portfolio tailored for showcasing expertise in Cybersecurity Engineering and Software Development.

## Overview

This repository contains the source code for a responsive, fast, and accessible portfolio website. It highlights personal projects, technical skills, and career roadmap, combining modern web aesthetics with semantic HTML and optimized performance. 

## Features

- **Minimalist Aesthetic:** Clean UI emphasizing content, utilizing a curated dark mode palette (glassmorphism accents and subtle gradients).
- **Fully Responsive:** Adapts seamlessly to all screen sizes (desktop, tablet, mobile).
- **Performance Optimized:** Uses native CSS features, lightweight JavaScript (GSAP for animations), and optimized asset delivery to ensure fast load times.
- **Dynamic Interactions:** Built with smooth micro-animations, scroll reveals, and interactive elements to provide a highly engaging user experience.
- **Accessible Design:** Employs appropriate contrast ratios, semantic tags, and accessible markup.

## Technology Stack

- **HTML5:** Semantic structure and accessibility.
- **Vanilla CSS3:** Custom styling, CSS Grid/Flexbox layouts, fluid typography, and responsive media queries (No heavy CSS frameworks).
- **JavaScript (ES6):** Logic and interactive elements.
- **GSAP (GreenSock):** Advanced animations (ScrollTrigger, ScrollToPlugin) for professional scroll reveals.

## Local Development

To run this project locally, simply clone the repository and open `index.html` in your favorite web browser. Or, you can use any local development server for a more robust setup:

```bash
# Clone the repository
git clone https://github.com/your-username/Aven.git

# Navigate into the project directory
cd Aven

# Run a local server (e.g., using Python's built-in http.server)
python3 -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.

## Deployment

This static site can be deployed easily to modern hosting platforms such as Vercel, Netlify, or GitHub Pages. The repository includes `.vercel` configuration out of the box for quick deployments.
